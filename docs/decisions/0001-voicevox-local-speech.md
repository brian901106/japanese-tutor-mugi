# 0001 地端語音：Claude 不必知道 VOICEVOX

- 狀態：已採用

## 背景
想讓家教的日文用動漫聲音念出來，嘴型也要對上。VOICEVOX 跑在使用者自己的電腦上，Claude 在雲端只寫文字。因此要做到：換聲音或換引擎不必改提示詞、嘴型跟著聲音走、VOICEVOX 沒開時仍能使用。

## 考慮過的選項
**A. 讓 Claude 用工具呼叫語音引擎**
- 優點：模型可以自己決定要不要念。
- 缺點：多一次來回，回覆變慢、多花 token；模型可能忘了呼叫。

**B. 請 Claude 回整段 JSON，裡面寫聲音名稱**
- 優點：欄位清楚。
- 缺點：要等整段收完才能顯示；提示詞得寫死聲音名稱。

**C. Claude 在每段標上語言，程式負責念（採用）**
- 優點：邊收邊顯示；模型完全不知道語音引擎；換引擎只改程式。
- 缺點：漏標日文就不會念，要靠伺服器防護補（見 [0004](0004-server-guards.md)）。

## 決定
手機把回覆切成中文段與日文段，只有日文段會被念出來。日文段送到伺服器的語音入口；選 VOICEVOX 時，伺服器先取得發音與每個音的長度，再產生 WAV 音檔。音節時間隨音檔一起回傳，手機依時間換嘴型。

## 做法
- 手機一邊收回覆一邊切段，只把日文段交給語音。
- 伺服器先向本機引擎問出發音與音長，再合成聲音。
- 音節時間一併回傳，手機依時間換嘴型。
- 引擎由設定頁啟動或關閉；找專案內約定的資料夾，或由環境變數 VOICEVOX_DIR 指定，找不到就拒絕啟動。附有下載腳本，下載後不需設定。

## 取捨
- 電腦要開著 VOICEVOX，而且它只負責日文；中文不走這裡，改用其他引擎。
- 第一次合成較慢（實測中位數約 3.7 秒），之後走語音快取（見 [0006](0006-tts-cache.md)）。
- 語音綁在某一台電腦上，不適合直接給別人用。

## 何時重新評估
- 要給別人用，不能依賴某一台電腦 → 改用雲端日文語音。
- 想讓角色依情緒換語氣 → 讓語氣設定也影響聲音（目前只保存，還沒影響聲音）。
- 中文也想要本機語音 → 另外找本機中文引擎。
